# TasRip

A Windows GUI for yt-dlp for Australian free-to-air catch-up: ABC iView, 10, SBS On Demand, 7plus and 9Now.
Successor to the Tas Rip Pack. WEB-DL only, no DRM.

**Get it:** download the zip from [Releases](../../releases), unzip anywhere, double-click `TasRip.bat`.
The first start downloads every tool it needs (yt-dlp, ffmpeg, N_m3u8DL-RE, aria2c, Streamlink, mkvmerge, SubtitleEdit, jq, wget).

**Update:** unzip the new version over your folder, then run `Update TasRip.bat`.

Full instructions are in [README.txt](README.txt).
