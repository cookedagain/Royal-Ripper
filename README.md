# Royal Ripper

A Windows GUI for yt-dlp for Australian free-to-air catch-up: ABC iView, 10, SBS On Demand, 7plus and 9Now.
Successor to the Tas Rip Pack (formerly TasRip). WEB-DL only, no DRM.

**Get it:** download the zip from [Releases](../../releases), unzip anywhere, double-click `RoyalRipper.bat`.
The first start downloads every tool it needs (yt-dlp, ffmpeg, N_m3u8DL-RE, aria2c, Streamlink, mkvmerge, SubtitleEdit, jq, wget).

**Update:** unzip the new version over your folder, then run `Update RoyalRipper.bat`.

**Coming from TasRip?** This is the same app, renamed. Unzip it into a new folder next to your TasRip folder and your settings come across on the first start, or unzip it over your TasRip folder and run `Update RoyalRipper.bat`. Details are in README.txt under "NEW IN 1.0.8".
